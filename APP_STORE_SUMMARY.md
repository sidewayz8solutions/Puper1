# Püper - Your Guide to Relief

## App Store Summary

Püper is a community-driven platform that helps people find clean, accessible public restrooms along their routes using precise geolocation and a unique 5-toilet rating system.

## Key Features

### 🗺️ Geolocation-Based Restroom Discovery
- Automatically finds restrooms near your current location
- Ranks restrooms based on proximity and user ratings
- Real-time location tracking for accurate results

### 🚽 Unique 5-Toilet Rating System
- Innovative rating system using toilet emojis instead of stars
- Comprehensive reviews for cleanliness, supplies, accessibility, and privacy
- Community-driven rankings based on real user experiences

### 🔍 Smart Search & Filters
- Find restrooms by wheelchair accessibility, baby changing stations, gender-neutral options
- Search along planned routes
- Filter by distance, ratings, and amenities

### 📱 Cross-Platform Availability
- Native iOS app with App Store distribution
- Native Android app with Play Store distribution
- Progressive Web App for browser access

### 🌍 Community-Driven Database
- User-contributed restroom locations and reviews
- Photo uploads to help others know what to expect
- Regular database updates with new restroom locations

## Technical Specifications

### Platform Support
- iOS 13.0+
- Android 7.0+
- Modern web browsers (PWA)

### Permissions Required
- Location access (to find nearby restrooms)
- Camera access (for photo uploads)
